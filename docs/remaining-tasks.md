1. **非同期API**: `eos()`メソッドが`Promise<Annotations>`を返す（kuromojiの制約）
2. **パッケージサイズ**: kuromoji辞書により約41MB増加
3. **stdin処理**: Node.jsの制約で全量読み込み後に分割（ファイルは行ごと処理可能）

1. **手動ビルドスクリプト**: napi-rsの設定問題を回避するため、手動スクリプトを採用
2. **ESM統一**: `.mjs`ファイルを使用してESM形式に統一
3. **型安全性**: `any`型の使用を最小限に抑制（リファクタリングポイントで指摘済み）
